# Mixed Economy Structure - Sonicity Game Design

## 📊 **Overview**

Sonicity implements a **multi-tier resource economy** with different value propositions for each resource type, creating natural spending progression from casual to whale players.

## 💰 **Resource Tiers & Pricing**

### **Tier 1: Basic Resources (Affordable)**
| Resource | Production Rate | Production Duration | Recharge Cost | Value per Unit |
|----------|----------------|-------------------|---------------|----------------|
| **Gold** | 1 gold/hour | 24 hours | 2.4 SONIC | 0.1 SONIC ($0.03) |
| **Food** | 0.5 food/hour | 24 hours | 1.2 SONIC | 0.1 SONIC ($0.03) |

**Purpose:** Entry-level resources for basic progression and building construction.

### **Tier 2: Premium Resources (Expensive)**
| Resource | Production Rate | Production Duration | Recharge Cost | Value per Unit |
|----------|----------------|-------------------|---------------|----------------|
| **Diamonds** | 1 diamond | 72 hours | 72 SONIC | 72 SONIC ($21.60) |

**Purpose:** Advanced building upgrades, premium features, competitive advantages.

### **Tier 3: Elite Resources (Very Expensive)**
| Resource | Production Rate | Production Duration | Recharge Cost | Value per Unit |
|----------|----------------|-------------------|---------------|----------------|
| **Rep** | 1 rep | 168 hours (7 days) | 168 SONIC | 168 SONIC ($50.40) |

**Purpose:** NFT minting, governance participation, revenue sharing access.

## 🎯 **Strategic Benefits**

### **1. Clear Resource Hierarchy**
- **Basic Tier:** Gold/Food for everyday operations
- **Premium Tier:** Diamonds for competitive advantages  
- **Elite Tier:** Rep for earning and governance

### **2. Natural Player Progression**
```
Casual Players → Basic resources (low spending)
Active Players → Basic + Premium (moderate spending)
Whale Players → All tiers (high spending)
```

### **3. Different Value Propositions**

#### **Gold & Food (0.1 SONIC each):**
- **Utility:** City progression, building construction, troop training
- **Accessibility:** Low barrier to entry
- **Volume:** High transaction frequency
- **Target:** All player types

#### **Diamonds (72 SONIC each):**
- **Utility:** Building upgrades, premium features, PvP advantages
- **Accessibility:** Moderate barrier (requires commitment)
- **Volume:** Medium transaction frequency
- **Target:** Active and whale players

#### **Rep (168 SONIC each):**
- **Utility:** NFT minting, governance voting, revenue sharing
- **Accessibility:** High barrier (serious players only)
- **Volume:** Low transaction frequency, high value
- **Target:** Whale players and serious investors

## 📈 **Monthly Spending Patterns**

### **Casual Player ($20-50/month)**
```
Daily Operations: 5-10 gold/food recharges = 12-24 SONIC/day
Monthly Basic: 360-720 SONIC ($108-$216)
Occasional Diamond: 1 diamond/month = 72 SONIC ($21.60)
Rep: Rarely
Total: 432-792 SONIC/month ($130-$238)
```

### **Active Player ($100-300/month)**
```
Daily Operations: 15-20 recharges = 36-48 SONIC/day
Monthly Basic: 1,080-1,440 SONIC ($324-$432)
Regular Diamonds: 2-4 diamonds/month = 144-288 SONIC ($43-$86)
Occasional Rep: 1 rep/month = 168 SONIC ($50)
Total: 1,392-1,896 SONIC/month ($418-$569)
```

### **Whale Player ($1000+/month)**
```
Daily Operations: 30+ recharges = 72+ SONIC/day
Monthly Basic: 2,160+ SONIC ($648+)
Premium Diamonds: 10+ diamonds/month = 720+ SONIC ($216+)
Regular Rep: 4+ rep/month = 672+ SONIC ($202+)
Total: 3,552+ SONIC/month ($1,066+)
```

## 💎 **Diamond Use Cases**

### **Essential Applications:**
- **Building Upgrades:** Advanced levels require diamonds
- **Premium Districts:** Exclusive buildings need diamond components
- **PvP Enhancements:** Diamond-upgraded troops/defenses
- **Speed Boosts:** Instant construction with diamonds
- **Competitive Advantages:** Higher efficiency, better yields

### **Strategic Value:**
- **Investment Multiplier:** Diamonds increase gold/food production efficiency
- **Competitive Edge:** Diamond users outperform basic players
- **Status Symbol:** Visual indicators of diamond upgrades
- **Time Savings:** Skip waiting periods with diamond payments

## 🏆 **Rep Token Economy**

### **Primary Uses:**
- **NFT Minting:** Convert rep to tradeable SonicityYieldNFTs
- **Governance Power:** Vote on game changes and proposals
- **Revenue Sharing:** NFT holders earn passive SONIC income
- **Elite Access:** Exclusive features and tournaments

### **NFT Value Creation:**
- **Passive Income:** Monthly SONIC distributions to NFT holders
- **Utility Bonuses:** Production increases, reduced costs
- **Governance Rights:** Community decision-making power
- **Social Status:** Leaderboards and achievement recognition

## 🎮 **Player Psychology & Engagement**

### **Progression Natural Flow:**
1. **Start Cheap:** "Let me try basic gold production" (2.4 SONIC)
2. **Scale Up:** "I need more resources" (multiple houses/farms)
3. **Premium Temptation:** "Diamonds look powerful but expensive..."
4. **Elite Commitment:** "I'm invested now, rep for serious gains"

### **FOMO Mechanics:**
- **Basic:** Accessible to all, builds habit
- **Premium:** Creates competitive pressure
- **Elite:** Exclusive earning opportunities

### **Investment Mindset:**
- **Gold/Food:** Operating expenses (necessary costs)
- **Diamonds:** Capital investments (efficiency gains)
- **Rep:** Asset acquisition (earning potential)

### **Monthly Game Revenue Sources:**
```
Basic Recharges (1,000 players): 200,000 SONIC ($60,000)
Diamond Recharges (300 players): 150,000 SONIC ($45,000)
Rep Recharges (100 players): 100,000 SONIC ($30,000)
Total Monthly: 450,000 SONIC ($135,000)
```
